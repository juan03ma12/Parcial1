# Overwatch - Base de Datos de Agentes

Proyecto web para la materia/taller HTML5 UP.
Temática: Overwatch
Servidor: GitHub Pages

## Archivos incluidos:
- 5 páginas HTML independientes.
- Hojas de estilo CSS personalizadas en assets/css/main.css.
- Scripts JS interactivos para filtrado de roles y contador.
- Estructura de fuentes Font Awesome 5 en assets/webfonts/.
