1. INFORMACIÓN DEL PROYECTO
--------------------------------------------------------------------
- Tema seleccionado: Overwatch - Base de Datos de Agentes
- Plantilla base utilizada: HTML5 UP (Dimension)
- URL de GitHub Pages: https://tuusuario.github.io/overwatch-site/
- Repositorio de GitHub: https://github.com/tuusuario/overwatch-site

2. DESCRIPCIÓN Y CAMBIOS REALIZADOS
--------------------------------------------------------------------
- Personalización completa del tema: Se adaptó la estructura y estilo 
  de la plantilla de HTML5 UP al universo del videojuego Overwatch.
- Estructura y Navegación: Se organized el sitio en 5 páginas HTML 
  independientes (index.html, heroes.html, mapas.html, multimedia.html 
  y contacto.html) conectadas mediante una barra de navegación semántica.
- Gestión de fuentes (Assets): Se integraron localmente los archivos de 
  fuentes iconográficas de Font Awesome 5 dentro de assets/webfonts/.
- Paleta de colores e identidad visual: Se ajustaron las reglas CSS 
  para utilizar los colores icónicos del juego (naranja #F99E1A, azul 
  oscuro #1A1E29 y acentos #00AEFF).
- JavaScript e Interactividad: Se crearon e integraron scripts de JS 
  personalizados para el filtrado dinámico de héroes por rol y un 
  contador de agentes activos.
